## ✨ المميزات الرئيسية

### 1. واجهة المتجر (Storefront)
- بنر رئيسي تفاعلي مع شعار براند مارك ذهبي.
- تصنيف المنتجات إلى: **الكل**، **رجالي**، **حريمي**، **للجنسين**.
- عرض تفصيلي لبطاقة كل عطر (الحجم، السعر بالجنيه المصري EGP، النوتات العطرية، وحالة التوفر).
- شكل زجاجة عطرية فاخرة مرسومة برمجياً أو صورة مرفوعة.

### 2. سلة التسوق الذكية (Smart Cart Drawer)
- فتح وإغلاق سلس لسلة التسوق.
- ميزة اقتراح شراء ذكي (**Smart Upsell**) لإضافة عينة اكتشاف (Discovery Sample).
- حساب فوري للإجمالي والكميات.
- خيارات دفع تناسب السوق المصري:
  - **الدفع عند الاستلام (Cash on Delivery)**
  - **فودافون كاش (Vodafone Cash)** مع حقل لإدخال رقم المحفظة المحول منها.

### 3. لوحة تحكم المالك (Owner Dashboard)
- **إحصائيات مباشرة:** إجمالي المبيعات، عدد الطلبات، وعدد الزجاجات بالمخزن.
- **تخصيص الهوية:** تغيير رقم محفظة فودافون كاش، نصوص البنر، واختيار لون البراند (Accent Color).
- **إدارة العطور:** إضافة عطور جديدة، رفع صور، تعديل الأسعار والمخزون، أو الحذف.
- **إدارة الطلبات:** جدول الطلبات الواردة بتفاصيل العميل وطريقة الدفع وحالة الطلب.
- **نسخة احتياطية (Backup):** تنزيل كامل بيانات المتجر في ملف `JSON`.

### 4. دعم اللغات والدعم المباشر
- زر تبديل فوري بين **العربية (RTL)** و **الإنجليزية (LTR)**.
- نافذة محادثة سريعة لخدمة العملاء وخبير العطور.
- حفظ جميع البيانات محلياً عبر `localStorage` لضمان استمراريتها دون الحاجة لقاعدة بيانات خارجية.
