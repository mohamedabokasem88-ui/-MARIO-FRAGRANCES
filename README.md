# MARIO | Luxury Perfumes Store

تطبيق متجر إلكتروني فاخر لعطور MARIO مبني كـ Single Page Application (SPA) عالي الأداء بتصميم أنيق داكن باللونين الأسود والذهبي، مع مزامنة سحابية حية مرتبطة تلقائياً بقاعدة بيانات Firebase (`my-amario`) وحماية كاملة لهوية البراند الأساسية.

---

## ☁️ المزامنة السحابية المدمجة (جاهزة للعمل فوراً)

- **رابط السحابة المربوط تلقائياً:** `https://my-amario-default-rtdb.europe-west1.firebasedatabase.app/mario_store_data.json`
- بمجرد فتح المتجر لأول مرة أو تعديل أي عطر أو سعر من **🔒 لوحة تحكم المالك** (`mario2026`)، يتم رفع البيانات تلقائياً للسحابة ومزامنتها لجميع الزوار على هواتفهم في نفس اللحظة.
