## 🌐 كيف تظهر المنتجات التي تضيفها أو تمسحها لجميع الزوار؟

المتجر يقدم لك خيارين متقدمين:
1. **استيراد ملف النسخة الاحتياطية بنقرة زر (📥 استيراد ملف منتجات JSON):**
   - من داخل لوحة المالك، اضغط زر **"استيراد ملف منتجات (JSON)"** واختر ملفك `MARIO_Store_Backup.json` ليتم تحميل صور العطور الأصلية كاملة وكافة التفاصيل في ثانية واحدة.
2. **المزامنة السحابية الحية (Cloud Sync - Realtime Database):**
   - لكي ينعكس أي عطر تضيفه أو تحذفه فوراً عند كل الزبائن على أجهزتهم دون تعديل الكود:
   - ضع رابط قاعدة بيانات سحابية مجانية (مثل Firebase Realtime Database: `https://your-project.firebaseio.com/products.json`) في خانة **المزامنة السحابية** بلوحة المالك واضغط **حفظ وتفعيل السحابة**.
   - من تلك اللحظة، أي إضافة أو تعديل أو حذف تقوم به كمالك يُحفظ سحابياً ويظهر لكل زائر في العالم فوراً.
3. **نسخ الكود بنقرة زر (📋 نسخ كود المنتجات):**
   - إذا كنت تستضيف الموقع كملفات فقط (GitHub Pages / Netlify)، اضغط **"نسخ كود المنتجات"** والصق الناتج في ملف `script.js` ليصبح دائماً للجميع.
