# MARIO | Luxury Perfumes Store

تطبيق متجر إلكتروني فاخر لعطور MARIO مبني كـ Single Page Application (SPA) عالي الأداء بتصميم أنيق داكن باللونين الأسود والذهبي، مع نظام حماية للمالك، وتحويل تلقائي للطلبات وخدمة العملاء إلى الواتساب (WhatsApp).

---

## 📁 هيكلية المشروع (4 ملفات فقط)

يتكون هذا المشروع من 4 ملفات أساسية وفقاً للمتطلبات:

```text
MARIO_Perfumes_Store/
│
├── index.html     # هيكل الصفحة وواجهة المتجر وزر الواتساب وسلة المشتريات ولوحة المالك
├── style.css      # التنسيقات العامة، المتغيرات اللونية، وتأثيرات أزرار الواتساب
├── script.js      # منطق التطبيق، إرسال الطلبات للواتساب، حماية المالك، وتحديث الحالات
└── README.md      # التوثيق ودليل الاستخدام وبيانات الأمان
```

## 📱 ربط الواتساب وتسجيل الطلبات (خانة المالك)

### 1. تسجيل الطلبات فوراً في خانة المالك:
- عند قيام أي زائر بإتمام الطلب من السلة، يُسجل الطلب فوراً في **جدول الطلبات الواردة** داخل لوحة تحكم المالك متضمناً:
  - رقم الطلب وتاريخ وساعة الإنشاء.
  - اسم الزبون، رقم هاتفه، وعنوانه بالتفصيل.
  - قائمة المنتجات والكميات والإجمالي بالجنيه المصري (EGP).
  - طريقة الدفع المختارة (الدفع عند الاستلام أو فودافون كاش مع رقم المحفظة المحول منها).
  - قائمة منسدلة لتغيير حالة الطلب (`جديد (قيد المراجعة)`، `تم التأكيد`، `جاري الشحن`، `تم التسليم`، `ملغي`).
  - زر **💬 مراسلة** لمراسلة الزبون على واتسابه مباشرة بضغطة زر واحدة.

### 2. تحويل الطلب تلقائياً إلى واتساب المالك:
- بمجرد تأكيد الزائر للطلب، يقوم المتصفح تلقائياً بفتح تطبيق / ويب الواتساب وتجهيز رسالة تفصيلية تحتوي على الفاتورة الكاملة وإرسالها لرقم واتساب المالك مباشرة للتأكيد والشحن.

### 3. خدمة العملاء عبر الواتساب:
- تم استبدال الشات التقليدي بزر واتساب عائم وأنيق (**خدمة العملاء - واتساب**) بتأثير نبض وإضاءة جذابة.
- عند ضغط الزائر عليه، يُفتح الواتساب مباشرة لمحادثة فريق الدعم والمالك للاستفسار وطلب النصيحة العطرية.

## 🔒 حماية وأمان لوحة التحكم (خاص بالمالك فقط)

- **بوابة دخول المالك:** عند الضغط على زر "🔒 لوحة تحكم المالك" يُطلب إدخال كلمة المرور.
- **كلمة المرور الافتراضية للمالك:** `mario2026`
- **تعديل رقم الواتساب وكلمة المرور:**
  من داخل لوحة التحكم (قسم إعدادات المتجر، الواتساب وفودافون كاش) يمكنك:
  - إدخال وتعديل **رقم واتساب المالك** (مثال: `010xxxxxxxx` أو `2010xxxxxxxx`).
  - تغيير **كلمة مرور المالك**.
  - تعديل رقم محفظة فودافون كاش ونصوص البنر ولون الهوية.
