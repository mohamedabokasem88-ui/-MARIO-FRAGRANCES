# MARIO | Luxury Perfumes Store

تطبيق متجر إلكتروني فاخر لعطور MARIO مبني كـ Single Page Application (SPA) عالي الأداء بتصميم أنيق داكن باللونين الأسود والذهبي، مع لوحة تحكم كاملة بدون كود (No-Code CMS) ومزامنة سحابية حية (Firebase Realtime Database) لإظهار التعديلات لجميع الزوار فوراً.

## ☁️ تفعيل المزامنة السحابية الحية (لإظهار تعديلاتك للناس)

من داخل **🔒 لوحة تحكم المالك** (كلمة المرور: `mario2026`):
1. ستجد في أعلى اللوحة قسم **"☁️ المزامنة السحابية الحية (لإظهار تعديلاتك لجميع الزوار فوراً)"**.
2. الصق رابط قاعدة بيانات **Firebase Realtime Database** (مثال: `https://your-project-id-default-rtdb.firebaseio.com/`) واضغط **"🔗 حفظ وتفعيل المزامنة"**.
3. من تلك اللحظة، أي تعديل في النصوص أو الأسعار أو العطور أو الألوان يتم رفعه تلقائياً للسحابة ويظهر لجميع الزوار على هواتفهم فوراً.
